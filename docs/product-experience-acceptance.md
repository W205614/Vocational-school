# 职学堂多角色迭代与验收

本轮覆盖选课、继续学习、交易、考试、教学、课程发布、复习、移动端、学情、运营、站内消息和一门实操课试点。运行验收使用独立 Compose 环境、合成账号和模拟支付。

## 交付内容

| 使用者 | 交付内容 |
| --- | --- |
| 游客 | 课程详情集中展示学习成果、先修要求、难度、实操说明、课时和试看入口。旧资料缺失时显示相应提示。 |
| 学生 | 「我的学习」直达上次小节、进行中的答卷和建议复习的错题。播放器根据服务端回执提示保存状态。课程讲义按学习权益获取。 |
| 学生 | 订单详情按课程展示支付、权益及退款节点，已生效的课程可直接进入学习。考试提供题号导航、漏答定位、交卷及评分回执，错题可按失分次数和复习时间推荐。 |
| 学生、教师 | 消息中心可直达答卷、课程答疑、售后和作业反馈。教师工作台可按课程处理未答问题、待评分答卷，并查看最近学习时间、章节完成情况和高频失分题。 |
| 管理员 | 上架前能预览学生看到的内容、集中查看阻塞项并跳转处理。草稿课程可以先配置试卷。运营工作台汇总待审退款、待开通权益和媒资处理失败。 |
| 实操作业参与者 | 管理员发布一项可选作业，学生提交作品说明和可选 HTTPS 链接，授课教师给出意见和处理结果。学生可按意见重交，各次提交和反馈分别留存。 |

## 验收记录

验收日期为 2026-11-22，分支为 `codex/product-experience`。网关镜像来自 `89b50c5`，其余四个应用镜像和两个网页镜像来自 `d483238`。两个源码提交之间的应用变更仅涉及媒资失败列表的网关路由优先级。启动后隔离环境 14 个容器全部健康，7 个应用和网页镜像的实际 ID 逐项匹配清单，5 个 JVM 容器内运行的 JAR 内容哈希也逐项匹配。支持服务候选镜像复用了本机已核对的媒资运行层，替换为本次候选 JAR，以处理 Alpine 下载中断。

- Java 定向回归通过 45 项，零失败、错误和跳过。网关修复后重新打包并通过 6 项网关策略测试。
- 前端类型检查、构建和 40 项单测通过。以实际运行应用导出课程、考试、学习、媒资、消息、交易的 OpenAPI 并生成前端类型。
- 4 项新增迁移的源码校验和均匹配隔离数据库的迁移记录。以原有课程数据和增量后的数据执行角色流程。
- Chromium 通过 14 项定向场景。另有 14 个测试实例按门户选择规则跳过。覆盖真实本地媒资播放、处理恢复、正常和零元订单、课程预览、讲义、作业反馈、考试及教学。390 像素窄屏通过讲义、作品提交和作答检查，并验证题号导航和漏答定位的键盘焦点。
- 最终网关的财务专项通过。覆盖支付事实及通知幂等、取消后迟到付款、并发退款、部分退款、其他订单的学习权益保留及管理员队列访问。
- Firefox 和 WebKit 在信任隔离证书的 HTTPS 环境各通过 2 项，零失败、零跳过。覆盖双门户会话刷新、购买后恢复学习、持久化笔记、教师入口和管理工作台。

核心购学考退、作品反馈和教师操作使用隔离后端、数据库与消息队列。草稿冲突、播放短尾等定向用例也包含可控的客户端响应。真机触控与全屏、真实供应商渠道和生产运行属于独立验收范围。

## 用户视角复盘

| 优先级 | 后续需求 | 验收标准 |
| --- | --- | --- |
| 高 | 批量盘点历史课程的选课资料。存量课程可以上架和学习，其新增字段仍可能为空。 | 管理员可以按缺失字段筛选课程、补录资料，并在学生页面核对展示结果。 |
| 高 | 为启用试看的课程增加上架前生成和预览试看片段。当前首次访问可能需要等待生成。 | 管理员能看到每个小节的试看就绪状态，学生打开已就绪的试看可直接播放。 |
| 中 | 为已发布作业增加有记录的更正和版本。当前作业发布后锁定说明。 | 教师和学生能看到当前说明、变更记录及自己提交时对应的任务版本。 |
| 中 | 把待反馈的实操作业合入教师工作台。当前阅卷和答疑在工作台集中展示，实操作业有单独入口。 | 教师从首页能一次查看三类待办并直达具体记录。 |

试点覆盖作品文字与链接的提交、反馈和重交。后续是否扩大到班级、学习路径或结课证明，依据真实教学试用结果评估。
