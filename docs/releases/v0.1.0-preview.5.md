# v0.1.0-preview.5 · 本机使用修复

本版基于 [preview.4](v0.1.0-preview.4.md)，适用于本机学习、体验和演示。使用 [源码 Tag](https://github.com/W205614/Vocational-school/tree/v0.1.0-preview.5) 获取本版，应用镜像按 [README](../../README.md#全新环境准备) 在本地构建。

## 修复内容

- 学生的限期免费课程权益到期后，课程仍开放报名时可以获得新一期权益。原订单和学习历史保留，有效期内重复报名继续使用本期权益。
- 报名窗口关闭后，课程页提示当前无法重新报名，既有学习记录仍可查看。统计按不同学生或课程计数，续报不会重复增加人数或课程数。
- 运维手册说明 preview.4 升级前恢复点的创建、校验和退役经过，恢复前按现有工具核对实际备份和配套镜像。

## 验证与升级

回归包含免费初次报名、有效期内重复报名、到期并发重报、报名窗口关闭、订单历史及报名人数。最终提交的检查结果见 [GitHub Actions](https://github.com/W205614/Vocational-school/actions)。

本版没有新增数据库迁移。已有部署按 [升级说明](../stability-operations.md#升级已有部署) 保留数据卷、配置和媒资。自动备份计划可按原有策略保持停用。
