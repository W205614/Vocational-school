# v0.1.0-preview.3 · 源码预览

2026-11-22 通过 [Git Tag](https://github.com/W205614/Vocational-school/tree/v0.1.0-preview.3) 发布，源码提交为 `230dae499f3045ebe26dc34f041a6f2e3d62be71`。公开交付以源码为限，应用镜像由使用者本地构建。

## 本版改动

- 游客和学生可按课程难度、预计时长和试看状态筛选课程。管理员可补录历史课程资料、查看字段变更记录，并按有效报名或已开始学习人数安排维护。
- 管理员可为草稿或已上架课程批量准备试看片段。媒资删除会核对已关联的课程和小节，避免破坏现有学习。
- 实操作业支持发布后更正、版本对照及站内提醒。教师可在教学待办中处理阅卷、答疑与作业反馈，并进入同一筛选范围内的下一项。
- 网关的跨域方法配置加入 `PATCH`，支持在 HTTPS 管理端保存课程资料。

## 发布时的验收

最终源码提交通过了后端、前端、CodeQL 和生产安全检查。[可靠性工作流](https://github.com/W205614/Vocational-school/actions/runs/45033387657) 的 Chromium 回归 85 项通过、71 个测试实例跳过，Firefox 和 WebKit 的核心冒烟各 2 项通过。隔离角色验收使用合成账号、模拟支付和本地视频，覆盖选课、学习、答疑、考试阅卷、退款及本版课堂流程。各轮环境与候选版本见[多角色体验](../product-experience-acceptance.md)、[四项后续需求](../product-experience-followup-acceptance.md)和[七项产品改进](../product-improvements-acceptance.md)。

## 2026-11-23 日常镜像隔离补验

隔离 Compose 使用与本机日常部署一致的 14 个镜像 ID、相同的网关 CORS 规则，以及独立数据库与合成账号，全部容器健康。管理员 HTTPS 来源的 `PATCH` 预检返回 200。Chromium 实际登录管理端并保存一门合成课程的资料，`PATCH` 返回 200。学生登录后刷新课程页读到新资料，原学习权益和独立草稿也通过检查。现有浏览器用例 1 项通过，零失败、零跳过。

补验所用的业务 JAR 和前端页面来自 `b74d6b0`，系统包和网关配置沿用日常部署的后续补丁。补验使用独立数据，日常容器保持停止。
