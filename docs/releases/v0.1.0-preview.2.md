# v0.1.0-preview.2 · 源码预览

本版本延续本机学习、体验和演示定位，保留既有技术栈与模拟支付、短信模式。Maven 和前端的 `1.0.0` 仍为构建版本。

## 本次修复

退出登录或切换账号会清空操作记录。此前，尚未返回的提交、结果查询或轮询没有完整接收取消信号，旧回执仍可能继续查询并将已经清空的浏览器记录重新写回。

双端现在将同一次操作绑定到开始时的取消信号，传递给提交、结果查询和轮询请求。清空记录时取消这些请求；即使响应已经到达，取消后的回执也不会继续写入记录。正常操作的幂等键、服务端失败信息和原请求重试保持现有行为。取消浏览器跟踪不会撤销服务端已经受理的业务，业务结果仍以服务端为准。

本版同时包含 [preview.1 的播放计时重试修复](v0.1.0-preview.1.md)。本轮未改变后端、数据库迁移、部署架构或业务素材。

## 验证与获取

新增五项回归覆盖提交、轮询、终态查询期间清空记录，以及正常成功、服务端失败回执；其中三项取消回归在旧实现失败。Windows 本地前端类型检查、38 项单元测试、学生与管理门户构建通过。最终提交的远程业务、前端、浏览器及安全检查以 [GitHub Actions](https://github.com/W205614/Vocational-school/actions) 中该 Tag 对应提交的结果为准；不将历史部署结果视为本版复测结果。

```powershell
git clone --branch v0.1.0-preview.2 --depth 1 https://github.com/W205614/Vocational-school.git
cd Vocational-school
```

随后按 [README](../../README.md#全新环境准备)安装依赖并构建。已有环境使用[升级说明](../stability-operations.md#升级已有部署)，不要重复初始化已有数据库。

本次公开分发为 GitHub 源码归档，不附带私有配置、账号、媒资、数据库或预构建应用。第三方源码、素材和二进制分发的授权仍未确认，不新增 MIT 或改变署名；应用包与 Packages 的公开分发保持受阻。

## 本机升级与边界

本轮日常升级目标为学生和管理两个网页镜像，后端仍使用原已部署镜像。升级前保留原镜像与运行配置绑定，验收候选网页后再替换，保留现有数据卷、端口、账号和媒资，不执行数据库迁移。此定向网页更新不使用要求完整备份的通用迁移升级入口，也不改变自动备份停用策略；配置原件和旧镜像不等同完整数据备份。实际升级与启停结果保存在本机维护记录，不提前声称完成。

真实供应商、生产部署、容量、高可用、外部告警与备份恢复仍未验收；历史凭据的撤销状态及此前五个本机 JVM 镜像扫描缺口仍按 [preview.1 已知边界](v0.1.0-preview.1.md#已知边界)处理。本项目没有模型或 Agent 功能。
