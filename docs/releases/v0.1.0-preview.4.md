# v0.1.0-preview.4 · 源码安全补丁

本版以 [preview.3](v0.1.0-preview.3.md) 为基础。源码通过 [Git Tag](https://github.com/W205614/Vocational-school/tree/v0.1.0-preview.4) 获取，应用镜像按 README 在本地构建。

## 修复内容

- 后端在读取课程答疑时检查课程权限，覆盖问题详情、按课程或小节的问题列表、回复和评论。学生需要有效课程权益，教师按授课关系访问，管理端仍可按权限处理答疑。
- 课程简介与管理端预览统一使用纯文本显示，兼容旧简介中保存的标签和空格。

## 验证

浏览器回归覆盖有权益学生和授课教师的答疑流程、退款撤销权益后的读取拒绝，以及包含旧标签的课程简介预览。修复记录见 [GitHub Code Scanning](https://github.com/W205614/Vocational-school/security/code-scanning)，最终提交的检查以 [GitHub Actions](https://github.com/W205614/Vocational-school/actions) 为准。

## 安装和升级

首次安装按 [README](../../README.md#全新环境准备)克隆 `v0.1.0-preview.4` 并构建。对已运行 `preview.3` 的环境，本补丁没有新增数据库迁移。已有部署按[升级说明](../stability-operations.md#升级已有部署)保留业务卷、媒资和配置。

真实支付、短信、对象存储与生产运行的适用边界见[生产就绪说明](../production-readiness.md)。
