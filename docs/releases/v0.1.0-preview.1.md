# v0.1.0-preview.1 · 源码预览

本版本供本机学习、体验与演示，采用源码构建方式。Tag 固定本次源码；`dev` 继续接收后续维护。Maven 和前端工作区的 `1.0.0` 是构建版本，不代表已完成生产验收。

## 本次修复

视频计时请求失败后，手动重试原心跳与新到达的心跳可能并发发送相同序号，较晚到达的旧回执还可能覆盖新状态。重试现在进入现有心跳队列，后续样本等待重试结果再分配序号；失败时保留原样本，切换小节或身份后丢弃旧队列。

本版本还包含此前已合入 `dev` 的职学堂命名、Windows 媒资路径限制、Windows 时区依赖及编码私钥检测规则。既有业务覆盖选课、模拟购买、播放与学习进度、考试与错题、积分赛季以及教师和管理员工作台，详见[学习与教学说明](../learning-experience.md)。

## 验证

2026-11-09 在 Windows 本机完成前端类型检查、33 项单元测试和学生／管理双门户构建。新增测试覆盖重试与心跳交错、重试再次失败和切换小节取消排队请求；并发回归在修复前可复现失败。

最终提交的远程业务、前端、浏览器与安全检查，以 [GitHub Actions](https://github.com/W205614/Vocational-school/actions) 中该 Tag 对应提交的结果为准。历史验收记录按各自日期、源码和环境解释，不作为本版本全部业务已重新本地验收的证明。

## 获取与运行

```powershell
git clone --branch v0.1.0-preview.1 --depth 1 https://github.com/W205614/Vocational-school.git
cd Vocational-school
```

随后按[README](../../README.md#全新环境准备)安装依赖并构建。已有环境按[升级说明](../stability-operations.md#升级已有部署)核对构建绑定、数据与恢复前置条件，不对已有部署重复执行首次初始化。

本次 Release 仅使用 GitHub 自动生成的源码归档，不附带本机配置、账号、课程视频、数据库、JAR 或容器镜像，也不发布 Packages。本机已有镜像和历史构建产物不因此成为该 Tag 的交付产物；本次没有升级日常部署。

## 已知边界

- 支付和短信默认为本地模拟；支付宝、阿里云短信及腾讯 COS 的真实账号完整流程仍需单独验收。
- 云部署、真实容量、多机高可用、故障切换、外部通知与备份恢复未完成目标生产环境验收。本机自动备份策略仍由部署者决定，源代码或运行数据不等于完整备份。
- 此前本机五个 JVM 镜像因 Java 漏洞库下载失败未完成本地扫描；同提交远程安全检查的覆盖范围与本机镜像扫描分别看待。
- 公开 Git 历史曾包含支付私钥，其真实用途和撤销状态未知；若曾用于真实账号，须由所有者在供应商侧撤销或轮换。本次不改写公开历史。
- 仓库没有统一 LICENSE，第三方源码和教学素材的再许可授权未确认。本次不新增 MIT、不改变原作者归属，也不授予第三方内容的新许可。依赖、源码与素材的使用和再分发须分别核实适用授权。
- 账户 Packages 列表查询返回 403，现有包的完整列表、可见性及源码绑定无法核实；本次没有发布包或镜像。

本项目没有模型或 Agent 功能，相应验收不适用。
