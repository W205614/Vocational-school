# v0.1.0-preview.6 · 多班级教务

职学堂支持同一课程同时开设不同班级，复用课程目录和学习进度。管理员可安排教师与助教、招生、补录和转班。学生可选班、提交作业、参加班级考试、查看答疑和成绩。教师可管理独立教学日程、批改、发布成绩和结班。详细流程见[班级教务](../classroom-teaching.md)。

## 获取与升级

首次部署克隆本版源码，再按[项目 README](../../README.md#全新环境准备)安装依赖和构建本机镜像。

```powershell
git clone --branch v0.1.0-preview.6 https://github.com/W205614/Vocational-school.git
```

- 数据库追加学习 V015、考试 V008、交易 V009，保留旧入口和历史记录。既有日常部署按[升级说明](../stability-operations.md#升级已有部署)核对停写恢复点、迁移和客户端配置。
- 验收范围包括班级权限、两班截止时间、课程权益、订单、作业成绩、班级阅卷和历史记录。使用隔离合成数据和本机模拟支付。持续维护聚焦可复现问题、明确需求和必要安全更新。

## 隔离验证

两个班级使用同一门课程。Chromium 走查覆盖模拟支付入班、不同截止时间、跨班访问拒绝、作业反馈、答疑和班级阅卷。真实 MySQL 回归覆盖最后一个名额、转班退款、个人延期、成绩发布与归档。两笔定向模拟退款均撤销了对应班籍。相关 CI 见 [GitHub Actions](https://github.com/W205614/Vocational-school/actions)。

发布提交 `2d362e841f84c3975c71448daf4bc2957c32c20c` 的浏览器检查通过 Chromium 86 项、Firefox 2 项和 WebKit 2 项。Chromium 的 72 项按测试所属门户跳过，三种浏览器均无失败。隔离恢复比对了 226 张表和 385 个媒资文件。本机日常环境应用三项迁移并通过清理后的冷启动检查。[发布提交检查](https://github.com/W205614/Vocational-school/commit/2d362e841f84c3975c71448daf4bc2957c32c20c/checks)
