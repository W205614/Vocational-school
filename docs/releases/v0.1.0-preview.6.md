# v0.1.0-preview.6 · 多班级教务

职学堂支持同一课程同时开设不同班级，复用课程目录和学习进度。管理员可安排教师与助教、招生、补录和转班。学生可选班、提交作业、参加班级考试、查看答疑和成绩。教师可管理独立教学日程、批改、发布成绩和结班。详细流程见[班级教务](../classroom-teaching.md)。

## 获取与升级

- 从源码 Tag 构建本机镜像，运行方式见[项目 README](../../README.md#全新环境准备)。
- 数据库追加学习 V015、考试 V008、交易 V009，保留旧入口和历史记录。既有日常部署按[升级说明](../stability-operations.md#升级已有部署)核对停写恢复点、迁移和客户端配置。
- 验收范围包括班级权限、两班截止时间、课程权益、订单、作业成绩、班级阅卷和历史记录。使用隔离合成数据和本机模拟支付。持续维护聚焦可复现问题、明确需求和必要安全更新。
