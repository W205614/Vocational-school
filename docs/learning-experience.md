# 学习、赛季与教学工作台

## 学生使用路径

游客可以浏览已上架课程、搜索分类和查看公开目录。已完结课程保留公开介绍，报名入口显示结束；草稿、已删除和下架课程不开放介绍。加入购物车或开始学习时进入登录页，登录后返回原课程；收费视频、答卷和个人记录仍需要服务端授权。

进入「我的学习」可设置每周完成的小节数量，查看本周进度，并从最近学习的小节继续。私人笔记支持课程筛选、关键词搜索和按记录的秒数回看。权益失效后已有笔记、进度与答卷保留，收费播放和学习写入停止。

「课程考试」保留草稿和版本冲突提示。整份答卷完成评分后才显示发布时的答案、解析与教师反馈；失分题进入「错题复习」。复习作答、标记掌握和重新复习保存到本人账号，不修改原考试成绩。主观题复习不自动判定正确。

## 积分和月度赛季

所有日期按 Asia/Shanghai 解释，一个自然月为一个赛季。

| 行为 | 积分规则 |
| --- | --- |
| 首次完成视频或考试小节 | 每小节 10 分，每日最多 50 分；重播、重考和重复事件不重复计分 |
| 每日签到 | 基础 1 分；连续签到 7、14、28 天额外奖励 10、20、40 分 |
| 学生回答被授课教师采纳 | 每个有效回答 5 分，每日最多 20 分；不能通过采纳自己的回答获取奖励 |
| 普通发言、笔记、评价 | 不计分 |

排行榜按积分从高到低、达到该积分的时间从早到晚、用户标识从小到大生成唯一名次。「积分与签到」可查看当月签到日历、积分明细、个人排名、历史榜、成就与奖励结果。首次结课、首次通过考试、连续七天完成学习可获得个人成就。

次月 2 日零点后，赛季任务核对生产事件及消费回执，再冻结最终榜。依赖不可用或事件未处理时显示等待核对，恢复后再次检查。最终榜保存昵称与名次快照；冻结后的迟到积分保留在账本及核对列表，不自动修改已结算名次。上线月份之前的积分仅形成只读历史，不补发成就或优惠券。

积分依据平台记录的完成状态发放，不代表核实了真实观看，也不是完整的防作弊机制。

## 教师与管理员

教师在「教学学情与答疑」选择所授课程，查看学生进度和待答疑问题，发布解答或采纳其他学生的有效回答。课程授课权限与试卷评分权限独立：授课关系不能代替评分授权，评分关系也不能获取其他课程学情。

管理员在「赛季与奖励」查看月份状态、积分来源和发奖结果。优惠券奖励默认关闭，只能配置尚未开始的赛季；启用的名次区间不得重叠，开始后规则锁定。发奖遵守优惠券发放期、库存、个人限领与有效期；失败有持久记录，管理员可以显式重试，重复消息不会再发一张券。

持有超过六张有效优惠券时，结算页允许选择最多六张参与方案计算；也可以不使用优惠券下单。优惠计算不可用时展示提示，不宣称得到了最优方案。

## 测试数据与证据边界

普通浏览器回归使用本机合成账号及新建课程等数据。包含历史榜、错题快照和奖励故障的高级测试只允许在明确的隔离副本或临时 CI 环境运行，不向保留部署补造历史赛季。

高级奖励测试预置的是待发请求，通过实际 Outbox、促销消费、库存扣减、券记录与回执完成发放；不直接写入成功状态。自然月结算边界另由可控时钟和真实数据库测试覆盖，不修改主机时间。代理多角色操作验收不等同于真人用户满意度研究。

恢复演练先核对备份原始表内容、媒资、Redis 和消息数据，再执行增量迁移及新镜像升级。演练使用独立项目、卷和端口，不能覆盖当前部署的业务历史。功能验证不包含真实支付、短信、生产容量或多节点高可用结论。
