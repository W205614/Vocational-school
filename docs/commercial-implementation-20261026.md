# 商业化优化交付记录（2026-10-26）

本轮交付代码、独立生产部署包和验收工具。没有可用的云环境或供应商测试账号，因此没有执行生产部署、真实支付、短信发送、COS 上传或跨可用区演练。99.9% 月可用性、RPO≤5 分钟、RTO≤30 分钟仍是待验证目标。

## 已实现

- compact 按顺序执行子模块启动任务，失败关闭上下文并阻止就绪；补充真实数据库下旧默认口令失效、重复启动及自定义密码保留验证。
- 应用配置、签名文件和本地媒资按应用分配。生产使用按调用方向分配的服务身份及受审 RPC 清单；支持接收端先更新的双密钥轮换，取消全局内部令牌。
- 独立生产安全约束拒绝模拟渠道、未认证中间件、不验证身份的 TLS、共享签名材料和不安全配置。应用存活与就绪分离，辅助搜索故障不阻塞核心就绪检查。
- 支付宝通知校验签名、商户、渠道与金额，沿用事务和幂等结算；删除支付敏感日志。本轮验证使用合成签名与测试数据，没有真实支付。
- 沿用腾讯 COS SDK，新增私有上传任务、独立扫描／探测／转码 worker、固定版本对象读取及原生视频播放。播放代理每次请求复核权益；课程封面使用受限 PNG/JPEG 私有对象和站内公开图片代理。未启用无法证明即时撤权的 VOD/CDN 分发。
- 公开注册、验证码、找回密码、管理员 MFA、隐私告知、账户资料导出与注销请求流程已接入。全域数据请求进入有版本和审计依据的人工处理流程；不把账户资料导出宣称为全部业务数据导出。
- 免费报名后显示权益准备状态，自动有界查询并支持超时后继续查询；不以订单成功代替权益到达。
- 独立 Kubernetes 部署渲染器要求跨区副本、受控入口、严格 mesh、最小挂载、独立 worker、托管中间件及外部可观测性。数据库工具支持新库初始化、校验和向前迁移和受保护的首个管理员创建。
- 增加实际解析的运行依赖 SBOM、源码／镜像版本绑定、依赖和密钥扫描及 CI 门禁。将共享恢复代码从历史部署目录抽出，保留兼容入口和原有备份格式。

## 本地验证范围

后端最终针对性批次通过 120 项测试、34 个测试类，另新增云封面 8 项通过，均无失败、错误或跳过。前端类型检查、权益准备单元测试、账户与购课页面契约测试通过；浏览器契约测试使用受控响应，不是云渠道验收。

后续 CI 还发现并修复了静态服务发现探针保持 UNKNOWN 的就绪问题，以及新增缓存头处理引起首次改密成功后缺少 JSON 响应的问题。前者使用实际 Spring Cloud 自动配置复现，保留嵌套必需组件故障阻止就绪；后者使用真实 MVC 参数解析与响应包装验证修复前失败、修复后通过。新增隐私表单后的个人设置测试按可访问表单名称定位，避免混淆两个密码输入框。

浏览器验收还发现立即领取优惠券的时间边界竞态：带小数秒的时间写入 `DATETIME(0)` 可舍入到下一秒。真实隔离 MySQL/JDBC 确定性测试复现修复前的发放与相对有效期失败；生成的即时起点现对齐到秒精度，四项测试通过，精确比较和预约时间语义保留。

托管数据库工具在隔离合成 MySQL 环境完成 380 次查询、41 项迁移及重复执行／管理员保护检查；这不证明托管 TLS 或实际生产权限已验收。生产工具最终 41 项自动化契约测试通过，并纳入 CI。

本地首次对实际解析的 340 项运行依赖生成 SBOM 并扫描，报告没有 HIGH／CRITICAL；修复后的 Web 镜像同级扫描通过。随后完整镜像扫描发现 SDK 内嵌旧 HTTP 库与基础镜像工具漏洞，说明普通依赖解析不能展开所有 shaded 内容。已改用官方普通 SDK 依赖，构造测试与最终 JAR 递归检查确认 HttpCore／H2 为 5.4.3，并固定经核实的 JRE 基础镜像。网关新增凭据转发契约验证也已通过。完整候选镜像、源码和最终提交的扫描结果以 GitHub CI 为准。这些扫描不代表没有漏洞，也不证明高可用或容量。

本轮仅启动独立合成 MySQL／Redis 测试容器，不修改日常部署数据；测试容器使用独立项目和临时文件系统。私有凭据、日志、恢复证据及既有 `deploy/docker` 材料不纳入提交。

## 2026-10-27 定点复审修复

本批只修复复审确认的五项问题，没有增加业务功能：退役旧学生改密入口及其网关／服务授权和接口声明；密码验证携带同一记录的身份版本，签发会话前发现版本或角色变化即拒绝；后台任务轮换起始类型并限制每类配额；登录记录复用现有持久任务和受管有界执行器，插入与任务完成同事务，入队失败不签发会话；生产云视频 GET 使用精确优先路由，普通 API 保留30秒总超时。

本地只执行修改和直接影响路径：首批19个后端测试类中的76项定向测试通过，无失败、错误或跳过；生产渲染与授权来源绑定14项契约测试通过，前端类型检查通过。复核补充了满队列空轮询不能消耗轮转顺序的边界，调度类另以5项用例复测通过。数据库和 Redis 测试使用新建的合成临时容器，结束后移除；日常14个容器的身份、镜像、挂载、端口与停止状态保留。本批未重建日常镜像，未执行真实支付、短信、云入口或供应商验收。新增回归已加入既有 CI，最终门禁另按推送提交的准确 SHA 核对。

## 环境具备后的验收

按 [生产部署说明](../deploy/production/README.md) 准备独立云资源和受保护配置，再执行只读预检、灰度和 [商业化运行手册](commercial-ha.md) 中的供应商、撤权、负载、故障及恢复演练。验收工具拒绝缺失、跳过、过期或版本不符的证据，不会由部署成功自动生成高可用结论。

支付／退款／对账、短信送达、对象权限和原生扫描转码、真实入口净化、告警与追踪脱敏，以及业务一致性和恢复时间仍需目标环境留证。JWT/JKS 与 MFA 主密钥的受控维护切换不等同于服务边令牌的在线轮换。异地备份策略由供应商实际配置并通过恢复演练确认，仓库中的策略文件本身不产生备份。
