# 生产就绪与外部服务接入

本轮已补齐短信回执、安全试看、完整隐私任务和生产接入工具，并完成下表列出的本地验证。真实供应商、云环境、容量与恢复待验收。默认本机使用模拟支付和短信；生产配置要求真实渠道，缺少配置时明确失败。

## 首次上线步骤

1. 按[生产部署说明](../deploy/production/README.md)准备独立候选资源、固定源码及镜像、受保护凭据；先执行空库初始化和前向迁移，再创建首个管理员。
2. 按[供应商接入手册](production-integrations.md)配置支付宝渠道和阿里云模板映射。配置命令可重复执行；已有编码对应内容不一致会失败，不自动覆盖运营配置。
3. 填写生产 settings、生成服务身份并渲染部署包。静态检查核对参数，连通性检查观察 TLS 和服务状态；业务验收另行执行发送、支付和送达流程。
4. 将部署包发布到候选环境，完成管理员改密与 MFA；执行运行验证工具，明确指定测试账号、课程和接收人。有写入的步骤必须显式启用，工具不会自行产生真实付款。
5. 执行支付、短信、媒体、隐私、负载、故障、恢复、外部告警与遥测脱敏验收，收集绑定候选版本的测量结果，再运行最终验收门禁。

命令参数、配置示例和返回状态以生产工具的 --help 及[接入手册](production-integrations.md)为准。缺失配置或外部环境时状态为 BLOCKED，补齐后重新运行。

## 短信处理与故障排查

公开账户验证码的有效期从申请时开始计算，排队时间不会延长其有效期。每个号码有独立发送记录：排队、提交中、供应商受理、已送达、失败、结果未知、过期；本地模拟另行标明。ACCEPTED 记录供应商受理，DELIVERED 记录送达回执。

网络超时、进程中断或旧记录缺少供应商关联信息时，不盲目再次发送。系统按已保存的流水与 OutId 查询回执；仍然无法确认的结果保留 UNKNOWN，供运营核对。确认拒绝的发送按有界策略重试，过期验证码停止发送。管理台“可靠性与补偿”查看逐号码的脱敏状态；旧腾讯、uCloud 占位适配不会参与真实发送。

先核对模板映射和签名是否启用，再核对凭据、供应商错误码及查询权限。日志和公开报告不得保存验证码、完整手机号、短信正文或原始供应商响应。

## 安全试看

试看使用独立截取的 MP4，默认时长一分钟，可通过 course.media.trailer-duration 配置，合法范围为 1～30 分钟。已报名用户继续使用完整视频；未报名的登录用户只能取得独立试看文件，服务端仅提供片段字节。

片段按源媒资版本和时长生成。本地由有界后台任务处理，云环境由现有独立媒体 worker 处理，复用 ffmpeg。处理中或失败时不发完整视频地址；页面可以继续查询，管理员可分页查看并基于版本重试失败任务。课程下架、取消试看或源媒资变化后，后续请求不再使用旧片段。

生产数据库权限需包含 media_trial：API 可 SELECT、INSERT、UPDATE，worker 可 SELECT、UPDATE；worker 对 media 需 SELECT、INSERT，并能读取私有 ready 对象以生成片段。对象仍通过站内鉴权代理读取，不能把源对象改为公开读。

## 完整隐私导出与审批清理

学生先在个人设置验证密码，下载既有账户资料并登记申请，再创建完整处理任务。管理员可以为待处理申请创建任务。任务 API 位于 /account-privacy/tasks，由现有 services/user 和 admin/user 网关前缀访问：

| 操作 | 方法及相对路径 |
| --- | --- |
| 创建任务 | POST /account-privacy/tasks，传 requestId 和 Idempotency-Key |
| 分页历史／详情 | GET /account-privacy/tasks；GET /account-privacy/tasks/{id} |
| 失败后继续 | POST /account-privacy/tasks/{id}/retry，传当前 version |
| 批准清理 | POST /account-privacy/tasks/{id}/approve，传当前 version、planHash |
| 下载 ZIP | POST /account-privacy/tasks/{id}/download，验证当前操作人 password |

身份模块通过内部服务身份逐域调用，不跨库查询。导出包含字段清单中的本人资料，不包含密码、验证码、密钥、会话令牌、供应商对象凭据或其他用户资料。data 域明确记录仅持有聚合统计的结论。完整导出按各域分页采集，各域采集时点独立，清单记录各页的采集结果与校验值。

任务在全部域完成后才进入 READY；每页有校验值，ZIP 包含 manifest.json，任务另保存整包 SHA-256。下载需要本人或管理员身份及当前操作人密码，运营需另行登记向申请人的实际交付。下载有效期为就绪后 24 小时；到期拒绝下载并清理数据库中间页。交付完成后，运营在原申请中记录真实交付证据；历史任务详情向管理员展示该证据引用、处理依据、操作人与登记时间。存在失败域时任务保持失败状态，可修复后续办。

生产通过身份应用独立的 PRIVACY_COS_SECRET_ID、PRIVACY_COS_SECRET_KEY 写入现有私有桶的 privacy-exports/ 前缀。身份 IAM 仅需此专用前缀的 PUT、GET、HEAD，以及核对桶 ACL/policy 的只读权限，不能复制媒体 worker 凭据。为该前缀配置对象及历史版本的短期生命周期，覆盖未提交成功的孤立包；不得将生产导出挂载成公开静态目录。工作 ZIP 仅在受保护临时目录创建，上传后清理。本机默认导出目录为 deploy/compact/.local/privacy-exports/private/：父目录由部署工具收紧权限，private 子目录由容器应用创建并设置权限。维护时将过期包移入回收站；导出包不属于日常业务数据备份。

生产 settings 的 privacy.retention 明确声明规则版本和 domain.dataset：

    retention:
      version: operator-policy-v1
      rules:
        learning.notes:
          days: 30
          action: ANONYMIZE

上例仅说明配置格式，30 天不是法律要求或通用建议。默认 UNCONFIGURED、空规则，全部保留。仅能选择代码已审阅且支持匿名化的数据集，不能上传任意 SQL。交易、支付和考试事实等只读数据集保留，并在清单中说明原因。注销账户保留必要关系，支持的数据集按审批规则匿名化。

清理仅针对已注销账户：先逐域生成影响清单，进入 APPROVAL_REQUIRED，由管理员核对当前规则、计划哈希与版本后审批。规则变化时旧审批不能继续；新建任务重新核对。分域执行幂等，失败不撤销已经完成的域，也不重新发起已提交的副作用。不得用旧数据库覆盖新增交易。

## 运行结果与验收边界

候选验证工具执行真实 HTTP 请求和声明的响应断言，收集脱敏观测、时间和哈希。支付、通知、隐私等功能分别核对持久业务状态与响应断言。云故障切换和恢复由平台控制面执行，工具收集其前后记录，不自动操作日常资源。

监控应同时检查用户侧成功率、延迟、排队时间、失败任务和短信指标采集新鲜度。backup_proof.py 校验平台提交的备份记录并输出 namespace 指标，实际备份与恢复由平台执行。将指标接入 Prometheus，并验证外部故障与恢复通知。

生产包启用 HTTP 延迟直方图，并生成网关请求速率、P95 和五分钟 HTTP 成功率的记录规则。成功率以 2xx/3xx 为成功、5xx 和429为失败，排除其他4xx及探针；无流量时该比例无样本。202 后的业务完成通过持久任务与端到端验收观察。配置依据见 [Spring Boot 指标说明](https://docs.spring.io/spring-boot/reference/actuator/metrics.html)。

本机备份仍按原决定停用，本轮功能不改变该策略。生产 99.9% 月可用性、RPO、RTO 和容量按真实运行数据与演练结果验收。
