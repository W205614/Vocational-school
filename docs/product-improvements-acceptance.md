# 职学堂七项产品改进验收

本轮实现了[上一轮角色复盘列出的改进](product-experience-followup-acceptance.md#角色复盘与后续清单)。验收日期为 2026-11-22，使用本机隔离 Compose、合成账号、模拟支付和真实本地媒资。

## 七项交付

| 使用流程 | 已实现的行为 |
| --- | --- |
| 管理员检查媒资引用并删除 | 删除前显示课程和小节，区分公开、下架与草稿引用。服务端在执行删除时再次核对引用。一批媒资有任一项正在被引用时，整批保留。已经进入删除流程的媒资不可重新关联。 |
| 学生接收作业更正 | 更正发布时向仍有权益且尚未通过作业的学生生成站内提醒。同一版本每人一条，打开后标记已读并进入对应版本。 |
| 教师连续处理待办 | 首页显示阅卷、答疑和待反馈作业的数量与最早等待时间。处理后可直接切换到同一筛选范围内的下一项。 |
| 学生、教师与管理员核对作业变化 | 学生和教师并排比较提交时与当前要求。管理员遇到并发修改时可载入最新版，保留本次编辑过的字段和更正说明，再明确发布。 |
| 管理员批量准备试看 | 草稿和已公开课程都可按整门课或所选小节组织试看生成。界面逐项显示等待、处理中、就绪、失败和源不可用等结果。 |
| 游客和学生比较课程 | 目录卡片展示难度、预计学习时长和试看开放状态，两类访客的服务端筛选口径一致。 |
| 管理员排定历史资料补录顺序 | 盘点可按当前有效报名或其中已开始学习的人数排序。字段历史记录补录前后的值、时间和操作者。 |

## 验收记录

隔离候选的 14 个容器均健康。7 个应用及网页镜像 ID、5 个运行 JAR 的摘要与清单匹配。教育服务为 `1a6faee`，支持服务为 `c64131b`，其余应用及网页镜像为 `847e808`。支持服务使用本机已验证的 Linux 媒资运行层，重新封装本轮支持服务 JAR。

- 隔离环境增量应用四项迁移，新增媒资引用保护、课程资料变更记录、学习人数查询索引，并将历史课程的搜索资料加入重投影队列。
- Maven 定向回归通过 56 项。真实 MySQL 覆盖媒资并发引用、批次保护、作业更正通知去重与回滚，隔离 Elasticsearch 覆盖目录投影。Linux FFmpeg 与隔离 MySQL 另通过 5 项媒资测试。两组均为零失败、零跳过。
- 前端类型检查与 40 项单测通过。课程、考试、学习、媒资、搜索的 OpenAPI 从实际运行的 servlet 导出并生成前端类型，原有契约路径全部保留。
- Chromium 走查验证了游客与登录学生使用相同筛选时的结果一致、管理员按人数排序和查看变更人，以及作业通知去重、点击已读、旧版对照与更正冲突保留输入。教师端另通过 4 条使用可控响应的浏览器回归，覆盖下一份作品、下一份答卷、跨问题切换及筛选分页。
- 真实购买、学习、答疑、考试阅卷和退款链路通过。复验修正了历史顶层回复使用 `answer_id=0` 时仍计为待答的问题。实际发布第一条教师解答后，计数减少，工作台直接打开同课程下一条问题。
- 两条真实媒资场景通过。草稿可批量生成，受引用媒资被拦截，下架后已报名学生仍能播放。无引用视频删除后从媒资列表消失，试图重新关联返回 409。已上架的历史课程可按小节或全课预生成，缺源小节独立显示，学生取得已就绪的实际片段。两条场景均在最终教育与支持服务组合上通过。

本轮共通过 5 条连接真实隔离后端的浏览器业务场景，以及 4 条教师端界面回归。参与角色为游客、学生、教师和管理员。原始记录位于本地 `.local/product-acceptance/.local/next-product/`，其中包含 `backend-result.json`、`media-native-db.log`、`runtime-images.json` 和各浏览器场景的验收日志。
