# 班级教务

同一门课程可以开设多期班级。视频、课程目录、个人笔记和学习进度按课程共享。班级的招生、名册、教学安排、作业、考试、答疑和成绩各自独立。

## 管理员

1. 在「班级教务」选择已上架课程，填写班名、招生和教学时间、名额及及格线。时间按部署使用的 Asia/Shanghai 时区填写。可以把往期同课程的教学安排复制到空白草稿，日期按两班开课时间平移。已开放解析的考核须选择替换试卷。
2. 分配至少一名教师，再发布班级。现有教师账号可在各班分别承担教师或助教职责。撤换唯一教师时先安排接手人。
3. 可补录已有课程权益的学生，保留补录原因。转班在同一课程内办理，目标班须有余位。课程进度随账号保留，旧班提交和成绩留在原班。停止招生后仍可处理已创建的订单。取消开班前应先处置名册、占座和退款。

## 教师与助教

- 教师可以安排课节、公告、作业和考试，调整个人截止时间和更正教学说明。作业提交绑定当时的要求版本。班级试卷由管理员在「试卷与评分」选择「班级专用试卷」发布，再由任课教师安排到考试窗口。一个试卷版本可用于多个班，待相关窗口全部结束后开放解析。解析开放后的版本不用于新的考试安排。
- 教师与助教均可回复班级答疑、反馈作业和阅卷。待办按班级统计。教师可确认成绩、导出本班已发布成绩、处理更正及结班。变更班级授权会影响后续 API、详情和导出的访问。
- 作业和考试按 0 至 100 分计入总评，考试取本次班级考核的最高有效分并换算为百分制。结班前考核权重须合计 100%，且已提交的答卷和作品须完成批改。缺交及到期未完成的重交计零分。学生本人可以查看已发布评分、评语及结班总评。已结班的成绩更正须填写原因。

## 学生

- 在课程详情选择班级。已有有效课程权益时可直接入班。付费班按课程标价结算，付费订单等待支付期间占用名额。关单释放占座，支付确认后入班，退款撤销对应班籍。课程访问权仍按剩余有效权益结算。
- 从「我的班级」查看日程、公告、作业要求版本、答卷、答疑和成绩。转班或退班后，可查看自己已发布的历史成绩。学习笔记和课程播放进度仍从原课程入口读取。

## 迁移与验证

迁移追加 tj_learning/V015、tj_exam/V008 和 tj_trade/V009。已有订单和教学记录保留原归属。升级前同步新 Feign 客户端配置、校验停写恢复点和对应镜像，使用隔离副本跑过迁移后再切换日常环境。沿用私有学习服务配置时，同步源配置中公开班级列表的精确免登入规则。部署步骤按[稳定性与运维说明](stability-operations.md#升级已有部署)执行。

日常使用以单机构和本机学习、体验及演示为范围。多班级完成后按可复现问题、明确需求和必要安全更新维护。
