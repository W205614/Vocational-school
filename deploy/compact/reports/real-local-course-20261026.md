# 真实本地课程与长视频播放交付

本记录对应“Java微服务实战”真实录屏课程。应用源码为 `487f7ba6d3054eb67596755d8b9c2ccb962c7155`；后续文档、测试提交与该运行源码分别记录，最终 GitHub CI 以交付回复中的准确提交和链接为准。

## 素材与兼容范围

素材来自用户本机提供的《天机学堂1.0》项目开发录屏：12 个 day 目录、161 个 H.264/AAC MP4，共 11,866,163,258 字节，原生 ffprobe 累计约 34.71 小时。它们是讲解平台开发的课程，不代表原有演示课程均已获得对应教材。原始文件只读，视频字节不提交 Git。

新课程独立、免费、长期有效；目录按自然顺序排列，小节名按既有 30 个 UTF-16 字符限制截短，完整文件名及源哈希保存在本机私有导入清单。课程目录按秒向上取整展示，新播放会话直接读取媒资毫秒时长计算 90% 门槛。旧媒资不自动回填；历史已完成记录、奖励与已有会话快照不追改。

## 实现与发现的缺陷

- 服务端 ffprobe 解析真实时长，支持无 Duration 字段 WebM 的时间戳回退，拒绝伪造文件、错误容器和未支持的视频编码；不做云转码或音轨兼容性认证。
- 上传复制与探测有并发许可、超时和输出限制。公开上传仍为 200 MiB；离线专用入口最多 512 MiB，要求显式启用、本地模拟 profile、服务凭证、管理员身份、固定只读根及源字节／哈希核对。
- 签名默认 600 秒，学生页面提前续期并恢复位置、倍速及暂停状态，沿用原计时会话；切节和退出取消旧请求，同账号令牌刷新保留播放器。续期重新检查课程权益。
- 新课程无订单时，原金额 SUM 返回 NULL 导致 500；现返回 0，未改变原统计口径。
- 学习人数 RPC 原服务端路径有重复前缀，现兼容既有路径并提供正确映射；服务凭证必验，拒绝网关来源，公开授权和公开接口契约一并移除。

## 日常发布与数据保全

七个应用／网页镜像已绑定运行源码，逐一核对 release tag、镜像 ID 与打包清单；日常部署通过既有升级工具更新，应用数据迁移为 0 项，原 MySQL／Redis／RabbitMQ 身份及数据挂载保留。新增课程使用独立业务 ID，导入完成后发布；课堂文件通过只读临时源挂载复制，播放不依赖原目录挂载。

升级前取得并完整校验了停写备份 `20261026T041957.744403Z`。另保存 22 张相关业务表的 1,644 条原行内容指纹和 59 个原媒资文件哈希；发布后的检查按原行和原文件是否仍保留判定，不能只看总数量增加。新增业务没有数据库迁移，因此本轮没有重复旧批次的全拓扑恢复或性能测试。

本机执行证据保存在 `deploy/compact/.local/real-course-20261026/`，只在相应检查实际成功后记录 `PASSED`：

- `candidate-image-proof.json`：七镜像来源与源码绑定。
- `primary-course-result.json`：全量媒资、课程目录、搜索、日常 600 秒票据和实际字节抽样。
- `history-preservation.json`：原行内容与原文件哈希。
- `runtime-preservation.json`：当前健康、原挂载与中间件身份。
- `final-backup-result.json`：包括新媒资的完整备份和当前镜像包。
- `retirement-result.json`：本轮临时资源退役清单及其他项目未变。

这些证据含本机路径、资源身份或业务标识，保持忽略；完成状态、当前运行数量、准确最终提交与 CI 链接在最终交付回复中提供。没有生成的文件不能当作已通过，历史批次的恢复证据也不冒充本轮重新执行。

## 实际边界

这是一套本机演示交付。真实课程文件不改变模拟支付／短信、单主机、本地存储的边界。未完整解码或连续播放全部约 35 小时，未测试生产并发、跨主机容灾、真实用户运营、真实支付或培训认证。签名地址是短期 bearer 凭据，不能宣称防分享或 DRM；完整备份会短暂停写，新增约 11.05 GiB 对象也需要相应备份空间。
