## 数据与恢复

独立恢复先核对最新备份的 12 个数据库、183 张表记录数与内容校验和、51 个对象文件哈希，再验证 Redis、消息队列、搜索投影和原账号历史读取。第一次浏览器执行 31 通过、1 失败：原测试学生累积超过 6 张有效优惠券，触发现有折扣方案限制，结算预览的 Feign 400 被展示为“远程服务暂不可用”。本轮不改变该业务行为，保留失败日志与 trace；原账号 9 个身份/历史接口通过后，在独立副本中新增学生账号，完整浏览器 32 通过、0 失败。未删除、过期或改写原账号的优惠券来制造通过。

搜索 9→7→9 在独立副本中执行；每阶段新增浏览器学生账号，保留前阶段全部业务主键。切换暂停写入，比较订单及订单明细事实指纹；重建搜索投影，核对可用课程、名称、销量及待处理任务。切换不恢复旧业务 SQL，最终部署保持 Elasticsearch 9.5.5。

## 复现与范围

```powershell
python deploy/acceptance/run_tests.py --suite regression
python deploy/acceptance/run_tests.py --suite core
python deploy/compact/run_backend_tests.py
python deploy/compact/run_transport_tests.py
python -m unittest discover -s deploy/compact -p "test_*.py"
python deploy/compact/check_policy.py
npm --prefix frontend run typecheck

```

前两项要求按部署手册准备独立回归库与环境；完整 compact 入口同时运行真实套接字回归。安全、审计、浏览器、Redis、备份恢复与功能证据门禁使用 [部署手册](../README.md) 的对应入口。独立演练中的新增账号凭证只保存在其私有目录，复查原历史必须先使用原账号。

本轮 `acceptanceScope=functional`，正式性能采样 `DEFERRED`；角色不适用的 20 个浏览器执行槽继续明确跳过。本机合成数据、模拟支付与短信、单机恢复的结果不代表真实供应商、生产容量或多节点高可用已验证。折扣方案的六券限制及其错误映射为现有行为边界，本轮没有覆盖超过六券后的成功购买。
